# OmniPost Composer

A small full-stack post composer. The React frontend lets a user create, edit, and delete posts for Twitter, Instagram, and Facebook. The Spring Boot backend provides the REST API and stores data in an in-memory H2 database.

## Project layout

- `frontend/` — React + Vite application (port 5173)
- `backend/` — Spring Boot + JPA + H2 API (port 8080)

See [setup_instructions.md](setup_instructions.md) for the VS Code run steps.
